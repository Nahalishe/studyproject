# Структуры данных и сортировки

[![Python tests](https://github.com/Nahalishe/studyproject/actions/workflows/ci.yml/badge.svg)](https://github.com/Nahalishe/studyproject/actions/workflows/ci.yml)

Учебный проект на Python 3.10+ без внешних зависимостей.

## Выполнение задания

| Пункт | Реализация |
| --- | --- |
| Массив | `structures.py`: `Array` — фиксированная вместимость, чтение/изменение по индексу, вставка, удаление |
| Список | `structures.py`: `LinkedList` — односвязный список, добавление с двух концов, поиск по индексу, удаление первого вхождения |
| Дек | `study.py`: `Deque` — кольцевой буфер, добавление/удаление с двух концов, просмотр по индексу |
| АВЛ-дерево | `structures.py`: `AVLTree` — вставка, поиск, удаление, симметричный обход, автоматическая балансировка |
| Сортировки | `sorting.py`: `bubble_sort`, `quick_sort` |
| Тесты | `tests/test_project.py` — все структуры и обе сортировки |
| CI | `.github/workflows/ci.yml` — тесты на Python 3.10–3.13 при push, pull request и ручном запуске |

## Запуск

```bash
python -m unittest discover -s tests -v
python study.py
```

На macOS/Linux при необходимости используйте `python3` вместо `python`.
Вторая команда запускает исходное интерактивное меню дека.

```python
from structures import Array, LinkedList, AVLTree
from sorting import bubble_sort, quick_sort
from study import Deque

array = Array(3)
array.append(5)
array.insert(0, 2)
print(list(array))  # [2, 5]

items = LinkedList()
items.append(5)
items.prepend(2)
print(list(items))  # [2, 5]

deque = Deque(3)
deque.push_front(2)
deque.push_back(5)
print(deque.pop_front())  # 2

tree = AVLTree()
for value in [30, 10, 20]:
    tree.insert(value)
print(list(tree))  # [10, 20, 30]
print(20 in tree)  # True
tree.remove(20)

print(bubble_sort([3, 1, 2]))  # [1, 2, 3]
print(quick_sort([3, 1, 2]))   # [1, 2, 3]
```

## Поведение и сложность

- Индексы массива, списка и дека неотрицательные. Массив выбрасывает `IndexError` для неверного индекса и `OverflowError` при заполнении. Список выбрасывает `ValueError`, если удаляемое значение отсутствует.
- Дек сохраняет поведение исходной программы: печатает сообщения; при пустом деке или неверном индексе возвращает `None`, при переполнении не изменяет данные. Вместимость массива и дека должна быть положительной.
- АВЛ-дерево хранит уникальные сравнимые ключи: повторная вставка ничего не меняет, удаление отсутствующего ключа вызывает `KeyError`.
- Сортировки возвращают новый список, исходные данные не изменяются. Элементы должны быть сравнимыми.
- Массив: доступ O(1), вставка/удаление O(n). Список: добавление O(1), доступ и удаление O(n). Дек: операции с концами и доступ O(1). АВЛ-дерево: поиск, вставка и удаление O(log n).
- Пузырьковая сортировка: O(n²), на отсортированных данных O(n). Быстрая сортировка: в среднем O(n log n), в худшем O(n²); используется итеративное разбиение на три части без ограничения глубиной рекурсии Python. Обе сортировки выделяют память под копию входа.

Тесты включают пустые структуры, переполнение, неверные индексы, переход через границу кольцевого буфера, все четыре случая поворотов АВЛ, проверку высот и баланса после вставок и удалений, повторяющиеся значения и случайные данные с фиксированным seed.
